COUNTRY INFLUENCER SETUP

Brand Collaboration page now has a golden “Choose county Influencer” button.
Select any listed country to show 10 influencer cards for that country.

Video files:
Put 10 portrait 9:16 MP4 videos in an “influencers” folder beside brand-collaboration.html.
Use this naming pattern:
  IN-01.mp4 ... IN-10.mp4   (India)
  US-01.mp4 ... US-10.mp4   (United States)
  GB-01.mp4 ... GB-10.mp4   (United Kingdom)
and so on using the two-letter country code shown in the dropdown.

Each card has its own Book Influencer button. The booking form receives that influencer’s code automatically.
Videos are muted, autoplay, loop, portrait, and intended for short example clips (around 10 seconds).
