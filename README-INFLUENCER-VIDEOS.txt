MERLIN AGENCY — INFLUENCER VIDEO CARDS

Each influencer card now uses a portrait 9:16 video area instead of a photo placeholder.

To add your own videos:
1. Prepare a portrait 9:16 MP4, ideally about 10 seconds long.
2. Put the MP4 file in the same folder as brand-collaboration.html.
3. Name them:
   influencer-001.mp4
   influencer-002.mp4
   influencer-003.mp4
   OR edit the src="..." filename in brand-collaboration.html.
4. The video will autoplay muted and loop on the card.
5. The influencer code and Book Influencer button remain underneath.

No Instagram ID / original-name label is used on the cards.
